系统封装，四步走

  1. 01

    进入审核模式

    在目标 Windows 中进入审核模式，以管理员身份运行程序。

  2. 02

    完成向导配置

    选择 Audit 或 OOBE、完成动作、计算机名、区域与账户设置。

  3. 03

    先生成测试文件

    Alpha 0.5 默认启用测试模式，仅生成应答文件，便于检查配置。

  4. 04

    确认并正式封装

    准备好后关闭测试模式，确认配置，执行 Sysprep 并验证首次启动。

常见问题

需要安装 Python 或其他运行环境吗？

不需要。Alpha 0.5 单 EXE 内置 Python 和界面运行库，启动时会自动释放所需文件。辅助进程在需要时独立运行，单文件分发不意味着全过程只有一个进程。

GUI 和 TUI 的封装能力有区别吗？

它们共用配置与封装流程。可以按 F8 从 GUI 切换到 TUI，或通过 --gui / --tui 参数直接选择界面。

是否所有 Windows 版本和配置都已验证？

没有。兼容列表基于维护者在指定虚拟机中的回归反馈，尚未覆盖每个 Build、服务器角色或账户组合。实际使用前，请用自己的镜像和设置进行验证。

JY Sysprep · JackYao233当前公开版本 Alpha 0.5 · 0.6 为未发布开发预览

想封装一个干净的系统，却可能被工具暗中改了设置。关掉捆绑选项，也未必能避开这些问题。

据火绒安全分析，某封装工具在普通封装模式下，即使未勾选附加组件，仍会在系统部署后修改浏览器主页并安装推广扩展，且未提供关闭或卸载选项。相关行为与封装模式有关，“防流氓／大客户”模式的封装产物未出现上述行为。

另一款软件，在简介中写明专业版“0 广告、0 推广”，需 VIP 权限下载使用。

我们的离线静态分析发现，其代码中存在浏览器主页修改及下载、运行外部文件的流程，并与 VIP 免广告状态联动。由于没有访问下载服务器或运行样本，尚不清楚实际会下载哪些文件、安装哪些软件。

JY Sysprep 不塞软件，不加推广。源码公开，让封装过程里的操作有据可查。

官方 Sysprep 界面的功能比较单一，主要用于选择启动模式、通用化和完成后的动作。想进一步设置语言、区域、OOBE 或用户账户，就需要配合应答文件等方式配置。

微软官方文档内容繁多，设置分散在不同页面，还要弄清配置阶段和适用条件。想改几个选项，往往得先翻文档、对参数，再编写和检查应答文件。

JY Sysprep 把常用设置放进同一个向导。选好选项，自动生成应答文件；先检查，再封装。少翻点文档，少写点脚本，把时间留给真正要做的事。

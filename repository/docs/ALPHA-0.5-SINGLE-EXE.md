# Alpha 0.5 单 EXE 候选版 3 x64

单个 EXE 随附 Python 3.6.8、GUI/TUI、NT 6.0 所需运行库、许可和无控制台辅助程序。
不需要安装 Python 或手动解压。启动时 PyInstaller 将资源释放到临时目录；
正式多系统封装所需辅助程序仍复制到受限的 ProgramData 作业目录，以独立运行。
这是单文件分发，并非封装全过程只使用一个进程或不产生临时文件。

在目标虚拟机中以管理员身份运行 EXE，默认 GUI，F8 可切换 TUI。
命令行可追加 --gui / --tui，--runtime-self-test / --gui-self-test / --self-test
运行只读 GUI 和运行时诊断，--admin-worker-self-test 仅诊断独立辅助程序。
自检不会执行 Sysprep、BCD 读写或关机/重启；正常向导默认测试模式。

本候选版把四套运行环境收敛为一套 Python 3.6 运行时，并重新构建主程序及辅助程序。
